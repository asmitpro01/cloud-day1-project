# Palamu Tiger Reserve — 30 s vertical reel (RCU)

1080×1920, 30 fps, H.264 + AAC, -14 LUFS. Built as an HTML map animation (D3, `window.seek(t)`)
captured frame by frame in headless Chrome and encoded with FFmpeg — the same approach as the
`map-animation` skill in `.claude/skills/`.

## Rebuild

```bash
cd reels/palamu-tiger
python3 -m http.server 8770 &                      # serve this folder
python3 render.py http://localhost:8770/reel.html renders/video_only.mp4 --fps 30 --w 1080 --h 1920
uv run python tools/music.py audio/music.wav 30.5  # regenerate the music (optional)
./tools/mix.sh renders/mix.wav                     # voice + ducked music, loudness-normalized
ffmpeg -i renders/video_only.mp4 -i renders/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart renders/palamu_tiger_reel.mp4
```

Preview any moment in a browser: open `http://localhost:8770/reel.html` and run `seek(12.5)` in the console.

## Swap in the official RCU logo

Put the logo at `assets/rcu_logo.png` (transparent PNG, about 200 px tall) and re-render. The page
uses it automatically; until then it shows a plain "RCU" text badge.

## Edit points

| What | Where in `reel.html` |
|---|---|
| On-screen text and timing | `CAPS` |
| Camera moves (lon, lat, zoom, tilt per second) | `CAM` inside `window.ready` |
| Pin positions | `PALAMU_PIN`, `RCU`, `BETLA`, `RESERVES` |
| Voiceover start times | `D=(...)` in `tools/mix.sh` |

## Sources

- **Boundaries:** India states and Census 2011 districts from [datameet/maps](https://github.com/datameet/maps) (Survey of India–aligned boundaries); other countries from Natural Earth via [world-atlas](https://github.com/topojson/world-atlas) (public domain).
- **Photos:** Wikimedia Commons, see `assets/photos/CREDITS.tsv` (file, author, license, page). CC BY / CC BY-SA photos need the author credit in the post caption.
- **Voice:** Kokoro-82M (Apache-2.0), Hindi voice `hm_omega`, generated locally.
- **Music:** generated by `tools/music.py` (no third-party samples).
- **Font:** Montserrat (SIL OFL).
